AAT-1: PORTFOLIO-DRIVEN - 15 MARKS
Building and showcasing practical projects through platforms like GitHub.
HARD COPY SUBMISSION DEADLINE: ON OR BEFORE 16-10-2026
Objective
To build a practical technical project and showcase it professionally through a portfolio platform such as
GitHub.
Activity Requirements
1. Create or update your GitHub profile.
2. Develop at least one practical project relevant to the course or your technical area.
3. Create a GitHub repository and upload the complete project source code.
4. Include a README.md with project title, objective, description, tools/technologies, execution steps and
output.
5. Add relevant screenshots and keep the repository organized and accessible.
6. Submit all required details as a hard copy report.

AAT-2: AI-AUGMENTED DEVELOPMENT - 10 MARKS
Using AI tools to enhance learning, coding, problem-solving and productivity.
HARD COPY SUBMISSION DEADLINE: ON OR BEFORE 20-11-2026
Objective
To demonstrate effective and responsible use of AI tools for learning, coding, debugging, problem-solving and
improving productivity.
Activity Requirements
Students may use tools such as ChatGPT, GitHub Copilot, Gemini, Claude or another relevant AI-assisted
development tool. Select a meaningful technical activity such as coding, debugging, understanding a concept,
generating test cases, code optimization, documentation, problem-solving or developing a small
feature/application.
Important: Students should understand, verify and modify the AI-generated output. Simply copying
AI-generated content is not sufficient.
AAT-2 Hard Copy Report Format
Section Details to Include
Cover Page Student Name, USN, Semester/Section, Subject, AAT-2 title, Activity/Project Title, AI Tool(s) Used
1 Title of the Activity / Problem
2 Objective and Problem / Task Description
3 AI Tool(s) Used
4 Prompt(s) Given to the AI Tool
5 AI-Generated Response / Solution
6 Student's Analysis of the AI Response
7 Modifications / Improvements Made by the Student
8 Final Code / Solution and Output Screenshots
9 Comparison: Without AI vs. With AI
10 Challenges / Limitations of AI
11 Learning Outcomes and Conclusion
Evaluation Scheme - AAT-2
Evaluation Criteria Marks
Appropriate use of AI tool 2
Quality of prompts and AI interaction 2
Technical implementation / problem-solving 3
Student's contribution and understanding 2
